Settings

OpenRouteService API key
Held in memory for this tab only — never written to storage, never sent anywhere except OpenRouteService. Free key at openrouteservice.org. Free tier: 40 routes/minute, 2 000/day.
Short-link resolver
Serverless function that expands maps.app.goo.gl links and proxies geocoding with a real User-Agent. Leave as /api/resolve on Netlify or Vercel; blank to disable.
Routing host
Routing comes from OpenRouteService on OpenStreetMap data, never from Google — Google's terms forbid exporting their directions. Two engines on two datasets will not pick the same roads; drag the pins or add stops to pin the shape down.
